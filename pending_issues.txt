# ScopeWatch Pending Implementation Issues

## Business Logic Alignment Issues

1. **Missing Public Verification System**
   - Description: The application lacks the necessary functionality for the public to search and verify organization certifications
   - Impact: High - Core business requirement not met
   - Solution: Implement search functionality in the public app with appropriate views and APIs

2. **Incomplete Audit-to-Certification Flow**
   - Description: No clear connection between successful audits and the issuance of certificates
   - Impact: High - Core business process not fully implemented
   - Solution: Create relationship between audits and certifications; implement workflow for certificate issuance

3. **Limited Consultant Documentation Features**
   - Description: No tracking for documentation prepared by consultants for organization certification
   - Impact: Medium - Important business function not implemented
   - Solution: Create ConsultantDocument model and appropriate workflow

4. **Basic Auditor Qualification System**
   - Description: Auditor qualifications tracked only as text rather than structured data linked to standards
   - Impact: Medium - Could lead to unqualified auditors being assigned
   - Solution: Create StandardQualification model to track which auditors are qualified for which standards

5. **Certification Scope Not Tracked**
   - Description: Certification model lacks a field for scope, which is essential for verification
   - Impact: High - Cannot verify the scope of certifications as required
   - Solution: Add scope field and related metadata to Certification model

## Data Model Improvement Needs

1. **Certification Request Process**
   - Add a CertificationRequest model to track requests from organizations

2. **Documentation Tracking**
   - Implement document tracking models for consultants, audits, and certification processes

3. **Audit Results Formalization**
   - Create a structured way to record audit outcomes that lead to certification decisions

4. **Role-Based Access Control**
   - Enhance the permission system for CertBodyUser and OrganizationUser models

## Frontend Requirements

1. **Public Certificate Search**
   - Create search interface for the public to verify certifications

2. **User Dashboards**
   - Implement role-specific dashboards for different user types

3. **Workflow Visualization**
   - Add UI components to visualize certification and audit processes

4. **Documentation Management Interface**
   - Create interfaces for uploading and managing certification documents
